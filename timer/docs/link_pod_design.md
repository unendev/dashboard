# 产品设计文档：链接收纳舱 (Link Station)

## 1. 核心理念
**“把浏览器还给浏览，把收藏还给直觉。”**
旨在解决开发者/学习者浏览器标签页（Tab）爆炸、收藏夹吃灰的痛点。提供一个独立于浏览器的、轻量级的、基于“当前关注上下文”的网页管理工具。

## 2. 产品定位
*   **入口**：Timer Widget 工具栏/右键菜单（与“提示词库”并列）。
*   **形态**：独立小窗口，极简设计，支持置顶。
*   **受众**：多任务并行的开发者、需要整理大量资料的学生。

## 3. 功能模块

### 3.1 极速收纳 (Quick Capture)
*   **剪贴板识别**：打开窗口时，自动检测剪贴板是否为链接，一键粘贴并抓取标题（如可行）或手动输入备注。
*   **拖拽支持**：支持从浏览器地址栏直接拖拽链接进窗口。

### 3.2 场景化分组 (Contextual Grouping)
*   不要传统的无限层级文件夹。
*   **采用“胶囊 (Capsule)”概念**：
    *   例如：“Vue学习”、“项目参考”、“稍后阅读”。
    *   每个链接属于一个胶囊。
    *   胶囊可一键“展开/折叠”或“一键打开该组所有链接”。

### 3.3 极简交互
*   **单击**：调用系统默认浏览器打开链接。
*   **右键**：编辑、删除、移动分组。
*   **搜索**：顶部全局搜索框，支持搜标题和URL。

## 4. 界面/交互原型 (UI/UX)
*   **尺寸**：默认 320x500 (同提示词库)。
*   **风格**：Dark Mode，磨砂玻璃感 (Acrylic/Mica)，强调信息密度与清晰度。
*   **布局**：
    *   Top: 搜索框 + 新增按钮。
    *   Body: 胶囊流 (Capsule Stream) 或 列表视图。
    *   Bottom: 状态栏 (链接总数)。

## 5. 预期价值
*   **减少焦虑**：通过“卸载”浏览器Tab压力，减少内存占用和心理负担。
*   **专注提升**：当前任务只打开相关的链接组，排除干扰。
