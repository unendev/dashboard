# 实现计划 - Todo-Memo 融合布局

## 概述

本实现计划将 Electron timer 项目中的 Todo 页面改造为融合式的两栏布局。任务按照增量开发的原则组织，每个任务都建立在前一个任务的基础上。

## 实现任务

- [ ] 1. 创建融合布局页面框架



  - 创建新的 `TodoMemoFusion.tsx` 页面组件
  - 设置基本的两栏布局结构（上方 Todo、下方 Memo、中间分割线）
  - 导入现有的 Todo 和 Memo 逻辑
  - 在路由中添加新页面（暂时保持 `/todo` 路由指向新页面）
  - _需求: 1.1, 5.1_

- [ ] 2. 实现分割线拖动功能
  - 创建 `Divider.tsx` 组件，支持鼠标拖动
  - 实现拖动时的高度计算逻辑
  - 添加最小高度限制（上方最小 100px，下方最小 100px）
  - 实现拖动模式的视觉反馈（光标变化）
  - _需求: 2.1, 2.2, 2.3, 2.4_
